# Gesture Swarm ROS 2: управление роем роботов по жестам

### 🛠️ Обзор инфраструктуры
Модульный пакет **ROS 2 на Python**, реализующий контур *perception-to-action* в реальном времени для управления группой мобильных роботов с помощью жестов. Система использует детектор **YOLO11n** и симулятор `turtlesim` для проверки кинематики, отделяя компьютерное зрение от фильтрации команд и управления приводами.

- **Репозиторий исходного кода:** [gesture-swarm-ros2](https://github.com/ajdanoff/gesture-swarm-ros2)
- **Документация бенчмарков:** [Benchmark Datasets Wiki](https://github.com/ajdanoff/gesture-swarm-ros2/wiki/Benchmark-datasets)
- **Ключевой стек:** ROS 2 (Humble / Lyrical) // Python 3.10+ // Ultralytics YOLO11n // OpenCV // RANSAC // `turtlesim`

---

## 🏗️ Модульная архитектура нод и топиков ROS 2

Пакет разделяет захват видеопотока, интерпретацию последовательностей и управление движением на три независимые ноды ROS 2 и два модуля чистой логики на Python:

```text
[ Видеопоток с камеры ] ──► gesture_detector_node (YOLO11n)
                                   │
                                   ▼ публикация в /gesture/symbol
                            command_parser_node
                            ├── symbol_filter.py (дедупликация символов)
                            └── command_parser.py (скользящее окно + RANSAC)
                                   │
                                   ▼ публикация JSON в /swarm/command
                            turtlesim_controller_node
                                   │
                                   ▼ публикация Twist в /turtle1/cmd_vel
                            [ turtlesim_node (симулятор кинематики) ]
```

### Основные компоненты пакета
* **`gesture_detector_node`:** считывает кадры с камеры (`camera_id`), выполняет инференс **YOLO11n** и публикует распознанные символы в топик `/gesture/symbol`.
* **`command_parser_node`:** отсеивает дублирующиеся кадры через `symbol_filter.py` и передаёт поток в `command_parser.py` для выделения устойчивых команд.
* **`turtlesim_controller_node`:** преобразует JSON-команды из `/swarm/command` в линейные и угловые скорости (`/turtle1/cmd_vel`).

## 🔬 Временной консенсус RANSAC и грамматика команд

Покадровое распознавание на живом видеопотоке подвержено кратковременным ложным срабатываниям. Чтобы исключить рывки приводов робота, в `command_parser.py` реализован многоступенчатый конвейер стабилизации:

1. **Дедупликация подряд идущих символов (`symbol_filter.py`):** подавляет дубли до попадания в буфер.
2. **Скользящее окно и консенсус в стиле RANSAC:** анализирует историю последних кадров и выделяет доминирующую команду движения (`A`, `B`, `F`, `L`, `R`, `U`, `D`), отбрасывая случайные выбросы.
3. **Аварийная остановка (Emergency Stop):** символ `A` обрабатывается с наивысшим приоритетом в обход накопления окна для мгновенной остановки агентов.
4. **Структурный парсинг задач:** поддержка составных директив (`T ...`) с сериализацией в JSON.
