## Архитектурная задача

Прямая генерация управляющего кода промышленного робота языковой моделью недопустима с точки зрения безопасности: любая галлюцинация LLM в углах суставов или последовательности перемещений может привести к физическому столкновению манипулятора с оснасткой или заготовкой.

В проекте реализовано жёсткое архитектурное разделение: **LLM выступает исключительно как семантический парсер намерений**, вызывающий строго типизированные инструменты **Model Context Protocol (MCP v2)**, а детерминированное ядро кинематики и геометрии работает как обязательный **Quality Gate** до компиляции программы контроллера.

```text

        │
        ▼  (Model Context Protocol v2)
MCP Server (Industrial-Robot-Welding-Simulator)
        │
        ├─► inspect_workpiece() / scene://workpiece/seams
        │        └─► Метаданные CAD-детали и доступные сварные швы
        │
        ├─► plan_and_simulate_weld(seam_ids, weld_speed_mm_s)
        │        ├─► Планировщик траектории (HOME -> APPROACH -> WELD -> RETRACT -> HOME)
        │        ├─► Решатель 6-DoF IK (аналитический якобиан + Левенберг — Марквардт)
        │        ├─► Контроль непрерывности суставов (защита от переворота запястья <= 120°)
        │        └─► Плотная проверка коллизий звеньев AABB (20 проверок на шов)
        │
        └─► export_robot_program(dialect="melfa" | "gcode")
                 └─► Постпроцессор контроллера (MELFA-BASIC / ISO G-code)
```

## Ключевые инженерные компоненты

### 1. Вычислительное ядро кинематики 6-DoF (`SE(3)` / `SO(3)`)
* **Прямая кинематика (FK):** цепочка однородных преобразований Денавита — Хартенберга (DH) от основания манипулятора до кончика сварочной горелки (TCP).
* **Аналитический геометрический якобиан:** прямой расчёт столбцов линейной ($J_{v,i} = z_i \times (p_{\text{tcp}} - p_i)$) и угловой ($J_{\omega,i} = z_i$) скорости в базовой системе координат.
* **Обратная кинематика (Damped Least Squares):** мультистарт-решатель по методу Левенберга — Марквардта с логарифмической ошибкой ориентации на $SO(3)$, демпфированием вблизи сингулярностей запястья ($\lambda = 10^{-4}$) и выбором наиболее плавной конфигурации суставов (точность `< 0.02 мм`).

### 2. Детерминированные Quality Gates и проверка коллизий
* **Непрерывность в пространстве суставов:** отбраковка траекторий со скачком обобщённых координат более `120°`.
* **Плотная проверка сварного шва:** дискретизация каждого линейного участка (`MOVL`) на 20 промежуточных точек и проверка пересечений всех звеньев цепи с объёмами стола и заготовки (`AABB`).

### 3. Постпроцессор управляющих программ
* Двухпроходный генератор кода, транслирующий проверенные опорные точки в синтаксис промышленного контроллера (**MELFA-BASIC** с командами `MOVJ`/`MOVL`, управлением дугой `HOPEN 1`/`HCLOSE 1` или **ISO G-code**).

## Бенчмарк GPU / CUDA пространственного индексирования

Для масштабирования проверки коллизий (Broad-Phase Collision Detection) на сложные CAD-модели реализовано **CUDA-ядро** отображения 3D-координат в одномерную **кривую Лебега (30-битные коды Мортона)** с раскладкой **Structure of Arrays (SoA)** для коалесцированного доступа к памяти GPU.

| Метрика / Конфигурация | Значение |
| :--- | :--- |
| **Объём 3D-сцены** | `1 000 000` примитивов |
| **CPU (векторизованный NumPy)** | `37.23 ms` |
| **GPU (NVIDIA T4 CUDA Kernel)** | `0.201 ms` |
| **Ускорение ядра на GPU** | **185.2x быстрее** (`100%` побитовое совпадение) |
