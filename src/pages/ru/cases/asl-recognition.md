# CI/CD-пайплайн бенчмаркинга моделей: распознавание жестов ASL

### 🛠️ Обзор инфраструктуры и эволюции моделей
Продакшен-ориентированный контур автоматизации для обеспечения строгих **Quality Gates** при выкатке моделей компьютерного зрения в составе роевой робототехнической системы ROS 2. Пайплайн автоматически конвертирует датасеты, применяет многопроходную генерацию ограничивающих рамок (bounding boxes) и запускает кросс-модельный бенчмаркинг на отложенных (held-out) веб-кам наборах данных для выявления domain gap до деплоя.

- **Репозиторий исходного кода:** [asl-gesture-recognition](https://github.com/ajdanoff/asl-gesture-recognition)
- **Активный запуск пайплайна:** [GitHub Actions Run #42774090717](https://github.com/ajdanoff/asl-gesture-recognition/actions/runs/42774090717)
- **Время выполнения CI-проверки:** `Успешно за 2 мин 6 сек`

## 🏗️ Архитектура и разделение на специализированные детекторы

Чтобы устранить визуальную путаницу между управляющими буквами и схожими по форме цифрами, единая 36-классовая сеть была разделена на два специализированных детектора:

```text
                                [ Входящий снимок / видеокадр ]
                                               │
                       ┌───────────────────────┴───────────────────────┐
                       ▼                                               ▼
         [ Specialist Digit Detector ]                   [ Specialist Letter Detector ]
         ├── 10 классов (0–9)                            ├── 26 классов (A–Z)
         ├── Вход: 512×512, AdamW                        ├── Вход: 512×512, AdamW
         └── mAP@0.50: 0.990                             └── mAP@0.50: 0.986
```

### 1. Матрица валидации и прирост метрик
Выделение цифр и букв в независимые модели дало заметный прирост точности и полноты на валидационной выборке:

| Архитектура модели | Оцениваемый домен | Precision | Recall | mAP@0.50 | mAP@0.50:0.95 |
| :--- | :--- | :---: | :---: | :---: | :---: |
| **Unified YOLO11n MP** | Все классы (36 классов) | 0.942 | 0.940 | 0.961 | 0.911 |
| **Specialist Digits (YOLO11n)** | Только цифры (0–9) | **0.989** | **0.982** | **0.990** | **0.933** |
| **Specialist Letters (YOLO11n)** | Только буквы (A–Z) | **0.976** | **0.964** | **0.986** | **0.903** |

### 2. Многопроходный конвейер разметки датасетов
Для формирования чистых YOLO-аннотаций из разнородных источников (Kaggle и веб-камера) реализован трёхэтапный fallback-алгоритм:
* **Первый проход:** извлечение координат кисти через `MediaPipe HandLandmarker`.
* **Второй проход (YOLO Fallback):** использование вспомогательного YOLO-детектора при сбое MediaPipe.
* **Третий проход (Centered Fallback):** расчёт нормированных рамок на основе статистики размеров класса.

## 🚀 Кросс-модельный фреймворк оценки в CI/CD

Стандартные утилиты оценки YOLO ломаются при сравнении специализированных моделей с объединённой, так как сужение списка классов сдвигает внутренние индексы (`class_id`). Для решения этой проблемы в `pytest` реализован **движок сопоставления по ASCII-символам**:

```text
[Ground Truth Class Index] ──► Перевод в символ (например, 'A')
                                      │
                                      ▼
                        [ Запуск инференса модели ]
                                      │
                                      ▼
[Model Predicted Index]    ──► Перевод через словарь names модели
                                      │
                                      ▼
                   Проверка: Символы совпадают && IoU >= 0.45
```

### Held-out веб-кам бенчмарки и анализ Domain Gap
Каждый коммит автоматически тестируется на двух независимых датасетах, опубликованных на Hugging Face:
1. **[ASL Webcam Benchmark — Original](https://huggingface.co/datasets/ajdanoff/asl-webcam-benchmark-original) (36 кадров):** базовый smoke-тест (1 реальный кадр на класс + фоновые кадры без рук).
2. **[ASL Webcam Benchmark — Augmented](https://huggingface.co/datasets/ajdanoff/asl-webcam-benchmark-augmented) (216 кадров):** стресс-тест с 5 детерминированными мутациями на каждый кадр (кропы, повороты, зеркальные отражения, сдвиги гаммы/HSV, размытие и шум).

* **Результат:** специализированный детектор цифр показал максимальную устойчивость (`60.00%` recall на оригинале и `41.67%` на аугментированном наборе при `0` ложных срабатываний на фоне), тогда как анализ ошибок выявил чувствительность хиральных жестов к горизонтальному отражению.
